# Welcome series: drafts for MailerLite

Five emails over ten days. Edit them into Ashley's voice before sending. Facts come from the site's own book pages. Replace `[BONUS LINK]` with the real bonus-chapters link, and add `?utm_source=email&utm_medium=welcome` to every ashleyclaudy.com link so the site and Amazon tracking can tell email sales from other sources.

**Merge tags:** `{$name}` is the subscriber's first name (MailerLite). **Segment:** the site sends each subscriber's `quiz_result` (`ride`, `hustle`, `outside-the-ropes`, `it-goes-on`, or blank). In the automation, add one condition per value and use that segment's block in emails 1, 3, and 4. Blank = use the "no quiz" block.
