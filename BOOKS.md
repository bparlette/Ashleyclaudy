# Ashley's Books

**How to update:** Edit this file in GitHub's web UI (pencil icon). Add a row for each book. The website updates automatically.

- **Title**: Book title
- **Series**: Series name (or "Standalone")
- **Status**: `out` (published), `soon` (coming soon), `writing` (in progress)
- **Date**: Publication date (YYYY-MM-DD) or expected date
- **Blurb**: One-line description
- **Amazon**: Amazon URL (or blank)
- **Cover**: Cover image filename in `assets/covers/` (or blank)
